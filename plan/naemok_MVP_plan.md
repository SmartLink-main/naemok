# 내몫 — MVP 기획서

> "내 조건에 맞는 정부 지원금을, 검색 없이 한눈에"

2026.03 | 1주 MVP + 2주 수익화 플랜

---

## 1. 문제 정의

대한민국에는 연간 수천 건의 정부 지원사업이 공고된다. 대부분 기업마당(bizinfo.go.kr)에 모여 있지만, 자영업자 대부분은 이 사이트의 존재조차 모르거나, 알아도 복잡한 필터와 어려운 공고문 때문에 포기한다. 결국 세무사를 통해 뒤늦게 알거나, 아예 놓친다.

*핵심 인사이트: 정보는 존재하지만 접근성이 낮다. '찾는 비용'을 제거해주는 것만으로 가치가 발생한다.*

## 3. JTBD (Jobs to Be Done)

**핵심 Job:** "내가 받을 수 있는 정부 지원금이 뭐가 있는지 빠르게 파악하고 싶다"

트리거 상황: 주변 사장님이 지원금 받았다는 이야기를 들었을 때, 뉴스에서 소상공인 지원 확대 기사를 봤을 때, 자금이 부족해서 외부 자금을 알아볼 때, 분기/연초에 새 공고가 대거 나올 때.

| 구분 | Job | 현재 불편함 | 내몫의 해결 |
|------|-----|-----------|------------|
| **기능적** | 내 조건에 맞는 공고만 보고 싶다 | 기업마당 필터 복잡, 자격 판단 어려움 | 3개 조건 입력 → 자동 매칭 |
| **감정적** | 나만 모르고 있는 건 아닌지 불안 | 관공서 시스템에 대한 두려움 | 쉬운 요약으로 두려움 제거 |
| **사회적** | 동료 사장님들 사이에서 유용한 정보 공유 | 공유할 정보가 체계적이지 않음 | 카카오톡 공유 기능으로 바이럴 |

## 4. 사용자 페르소나

### 메인: 김영수 (46세, 삼겹살 식당 사장)

서울 마포구에서 식당 운영 4년차. 직원 2명, 연매출 약 3억. 스마트폰은 잘 쓰지만 PC 작업은 서툴다. 네이버 카페에서 정보를 얻고 카카오톡이 주 소통 수단. 작년에 세무사가 알려줘서 소상공인 안정자금 500만원을 받았고, 이후 직접 찾아보려 했지만 기업마당이 너무 복잡해서 포기했다.

*"세무사가 알려주기 전까지 몰랐어요. 자동으로 알려주는 게 있으면 좋겠다고 생각했는데."*

**내몫 이용 시나리오:** 네이버 카페에서 "지원금 쉽게 찾는 사이트"라는 글을 보고 내몫에 접속 → 업종(음식점), 지역(서울 마포), 사업기간(3년 이상) 선택 → 맞는 공고 5개 확인 → 요약 읽고 세무사에게 카톡으로 링크 전달 → 이후 새 공고 알림 받고 싶어짐 → 유료 구독 전환

### 서브: 이수진 (31세, 카페 창업 준비 중)

대기업 퇴사 후 6개월 내 카페 오픈 예정. IT 리터러시 높음. K-Startup, 소진공, 서울시 창업 지원 등을 알고는 있지만 공고마다 조건이 달라 하나하나 확인이 번거롭다. 이미 2개 탈락 경험이 있어 '되는 것만 빠르게 보고 싶다'는 마음이 강하다.

**내몫 이용 시나리오:** "예비창업 지원금" 검색 → 내몫 발견 → 업종(카페/음료), 지역(서울), 사업단계(예비창업자) 선택 → 맞는 공고 8개 확인 → 매주 접속해서 새 공고 확인하는 패턴 → 알림 기능 유료 전환

### 이탈: 박준호 (38세, IT 스타트업 대표) — 타겟 아님

이미 기업마당을 직접 쓰고, VC/액셀러레이터에서 정보를 얻는다. 필요한 건 탐색이 아니라 신청 대행이나 컨설팅. 이 유저를 위한 기능을 만들면 핵심 타겟의 경험을 해친다.

## 5. 프로덕트 정의 (MVP)

### 무료 플랜 (1주차)

| 포함 | 제외 |
|------|------|
| 랜딩 (이번 달 지원금 TOP 10) | 회원가입/로그인 |
| 조건 입력 (업종/지역/사업단계) | 알림 기능 (2주차 유료) |
| 추천 공고 + 전체 공고 리스트 | AI 자격 분석 |
| 공고 상세 (요약 + 원문 링크) | 모바일 앱 |
| 카카오톡 공유 버튼 | 북마크/저장 |
| 알림 사전등록 폼 | |

### 유저 플로우

```
[내몫 랜딩]
  → '이번 달 TOP 10' 즉시 노출 (검색 불필요)
    → 더 맞춤 결과 원하면 조건 입력 (업종, 지역, 사업 단계)
      → 추천 공고 N개 + 전체 공고 목록
        → 카드 클릭 → 공고명, 지원금액, 마감일(D-day), 자격 조건 요약, 원문 링크
          → 하단 배너: '새 공고 알림 받기' 사전등록 (이메일/전화번호)
```

**핵심 UX 원칙:** 3클릭 내 결과 도달, 회원가입 제로, 모바일 퍼스트, 관공서 용어를 쉬운 한국어로 풀어쓰기.

## 7. 유입 전략

자영업자는 광고보다 '유용한 정보 콘텐츠'에 반응한다. 커뮤니티 대부분이 홍보글을 금지하므로, 직접 홍보가 아닌 콘텐츠 마케팅으로 접근한다.

**핵심 콘텐츠:** "2026년 N월 자영업자 지원금 총정리" — 매달 발행하는 정리 글이 네이버 블로그, 카페에서 SEO 유입을 만들고, 글 하단에 내몫 링크를 자연스럽게 노출한다.

| 채널 | 접근법 |
|------|--------|
| 네이버 블로그/카페 | 월간 지원금 총정리 콘텐츠 발행 → 검색 유입 → 내몫 링크 |
| 자영업 오픈채팅 | 유용한 정보 공유 맥락에서 내몫을 자연스럽게 소개 |
| 카카오톡 공유 | 내몫 결과 페이지 공유 버튼 → 사장님 단톡방에서 바이럴 |
| 랜딩 TOP 10 | 검색 없이 즉시 가치 제공 → 이탈률 감소, 재방문 유도 |

## 9. 확장 로드맵

내몫의 진짜 수익은 알림이 아니라, '알림 → 신청 도우미 → 대행'으로 이어지는 밸류체인 확장에 있다. 지원금 500만원의 대행 수수료 10%는 50만원이고, 이 시장은 이미 존재한다.

| 시점 | 추가 기능 | 수익 효과 |
|------|----------|----------|
| 1~2개월 | AI 자격 분석, 신청 체크리스트 | 유료 기능 강화, 전환율 상승 |
| 3~6개월 | 신청서 작성 도우미, 세무사 연결 중개 | 건당 결제 + 중개 수수료 |
| 6개월+ | 신청 대행, B2B (프랜차이즈), 대출/투자 확장 | 객단가 대폭 상승 (건당 수십만원) |
